# Morfeo UI: responsive panels and the Smith CLI dashboard features

Objective: fix the convocatorias prototype interaction; make every Morfeo UI panel responsive and functional across viewports; and bring the Smith (papersmith-ai 0.81.0) dashboard CLI features to Morfeo UI: update button, current status and pending report, CLI button and alert, CLI activation, mirror and socket settings.
Branch `feat/ui-smith-responsive` (stacked on `feat/convocatorias`); prototype fixes go to the `gh-pages` branch. Delivery `single-pr`, no push of feature branches unless asked. Tests: `uv run python -m unittest discover tests -p "test_*.py"` and `node --test tests/js/*.test.mjs` (jsdom from an external install).

L1b (2026-11-20, analysis of S1): labels had `pointer-events: none`, so a click on a name fell on the SVG background, started a captured drag and lost the click; node hit area ~9 px; the side-by-side tree scrolled horizontally inside `.groups`, so link overlays misaligned; on narrow screens the detail panel sat below the whole view, so a tap looked like nothing happened. Fix: every node labelled in two side columns with leader lines; labels and a wider ring clickable; drag only after 4 px; background click clears the selection; zoom buttons; groups wrap; bottom-sheet detail under 1080 px.

L2 (2026-11-20, comparison map, Smith = ~/Documents/papers_smith/papersmith-ai 0.81.0):
- Update button = Smith «⟳ Actualizar tablero»: `board_refresh.refresh_artifacts()` runs local keyless generators (ok/skipped/failed), `POST /api/board/refresh` (same-origin, lock, 409 when busy), `GET /api/board/summary`, refresh at start unless `--no-refresh` (commit 7d1dcb37, 0.79.0). Smith has no PyPI check; it warns when the server is older than the installed kit and serves static files no-cache. Morfeo's «⟳ Actualizar» only re-fetches /api/status and the server ignores `fresh`.
- Status report = `summarize()`: current phase (first not passed, never transversal), missing steps, open and failed gates, failed artefacts, next command, tone (alert/warn/done/info). Morfeo has the data (control.next_command, gates, pipeline_units, unit_progress) but no consolidated report; `morfeo status` prints counts only.
- CLI button and alert: Smith never blocks the embedded CLI; a missing tool only disables the external launch button with a tooltip; missing agents are disabled; quick commands come from `.claude/commands`. Morfeo closes the embedded terminal and shows a blocking modal when herdr or Ghostty/WezTerm is missing, keeps missing agents selectable and has two hard-coded quick commands.
- «Activar CLI»: Smith exchanges a login secret for an HttpOnly SameSite=Strict cookie, `POST /api/terminal/activate` (same-origin guard, throttle, URL from the bound loopback socket), activation only on click, Origin/Host guard on every terminal route (commits 8c54fc97, 2a6af90a, f2964108, cef18be3, 678e15db). SECURITY GAP: Morfeo has no token, cookie, Origin or Host check on any route; `/ws/terminal` accepts any client (cross-site WebSocket hijacking risk, not exploited here); POST routes have no same-origin check.
- Mirror: Smith's «mirror» is the herdr agent in the PTY after `ensure_herdr_workspace`; Morfeo already has the same. Morfeo's `run_pane_mirror_session`/`forward_input_to_pane` (terminal.py:449-614) are dead code since 13eab02.
- Sockets: Smith has no WebSocket settings (SSE + POST); its socket-related settings are activation from the bound socket, browser opening through Wayland/X11 display sockets with WSL and headless handling (dbbc66a2, 0.79.1), and bind options (`--lan`, `--network-terminal`, `--allowed-host`, refusal of non-loopback without auth). Morfeo keeps its stdlib WebSocket (15 s ping, 600 ms reconnect, takeover); it binds 127.0.0.1 only, opens the browser before binding with plain `webbrowser.open`, and has no Host allow-list. Interpretation of «sockets» as these settings is an assumption.
- External terminal: Morfeo probes only Ghostty/WezTerm and uses macOS-only `open -a` everywhere; Smith probes ghostty, wezterm, gnome-terminal, konsole, x-terminal-emulator with per-terminal argv.
- Constraints: Smith runs FastAPI/uvicorn/watchfiles in a provisioned venv; port behaviour only onto Morfeo's stdlib ThreadingHTTPServer and WebSocket; keep polling instead of watchfiles; no LLM calls.
- Proposed units: U0 extraction (terminal controller to static/cli-console.js, terminal handlers to dashboard/terminal_routes.py; no behaviour change); U1 board refresh + summary + stale-server warning; U2 activation, cookie, Origin/Host guard on POST and WebSocket, non-blocking alert, disabled missing agents, quick commands from .claude/commands (high risk: security); U3 Linux terminal launch + dead mirror code; U4 browser opening via display sockets, open after bind, `--no-refresh`, `--no-terminal`, optional `--allowed-host`. Smith tests to mirror: test_command_center_board_refresh.py (20), test_command_center_cli_activation.py (9), auth/guard parts of test_command_center_terminal.py, test_command_center_open_browser.py (14).
