# Convocatorias: reliable national (Colombia) search

Objective: make the funding-call search cover Colombia for real (Minciencias, SGR, ministries, UNAL, local and national business challenges) and catch coverage gaps deterministically.
Branch `feat/convocatorias-nacional`, stacked on `feat/idioma-tablero-traduccion` (41c10c7; it touches the same panel and is not merged). Delivery `ask-on-risk`. Tests: `uv run python -m unittest discover tests -p "test_*.py"` and `node --test tests/js/*.test.mjs`.

## Specs

S1. National coverage (L1, verbatim): «depura el buscador de convocarorias, asegurste de incluir convocatorias disponibles de minciencias, sistema general de regalias de ministerios en colombia, de la unal por el hermes o siun, de retos enpresariales locales y nacionales, depura muy bienla busqueda nacional». Acceptance:
- The source catalog (`scripts/convocatorias/fuentes.json`) lists the verified Colombian listings (L2) with their real listing URL, method (`api`, `rss`, `html`, `pdf`, `busqueda`, `sesion`), level (`nacional`, `regional`, `local`, `institucional`), whether the national search must consult it, crawl limits and query templates for search-only sources.
- The agent consults every mandatory Colombian source on each search, uses the APIs and feeds before HTML, reads closing dates from detail pages, runs Colombian query templates (including the local level of the profile's city and department), and records each call with its level and a source id from the catalog or `busqueda:<host>`.
- Hermes is reached only with the operator's open session; without it the source is recorded as needing a session and the UNAL Vicerrectoría de Investigación API stands in (assumption L2).
- `check` fails when a mandatory Colombian source was not consulted, when a source's reported count does not match the calls registered from it, when `fuente` is neither a catalog id nor `busqueda:<host>`, or when two calls share a normalized URL.
- Eligibility rules cover Colombian calls (Minciencias, SGR CTeI, UNAL internal, iNNpulsa and business challenges, Fondo Emprender), and the dashboard shows and filters the level.
- Proof: a real search on the hermes project registers open Colombian calls.
